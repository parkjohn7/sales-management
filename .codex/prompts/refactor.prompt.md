# Refactor Prompt

This is a behavior-preserving refactor.

## Goal

<describe refactor goal>

## Non-goals

- Do not change public behavior.
- Do not change API contracts.
- Do not change database schema.

## Required process

1. Identify current behavior and affected tests.
2. Generate impact map.
3. Produce execution plan.
4. Implement in small steps.
5. Run existing tests.
6. Add tests only if current behavior is under-tested.
7. Report behavior preservation evidence.

## Done when

- All existing tests pass.
- No public behavior changed.
- Complexity is reduced or structure is clearer.
