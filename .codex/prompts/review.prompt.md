# Code Review Prompt

Review the current diff against:

- Task spec
- AGENTS.md
- `.harness/rules/review-rules.md`
- `.harness/templates/code-review-checklist.md`

## Review output format

### Summary

### Blocking issues

### Non-blocking issues

### Missing tests

### Architecture risks

### Security risks

### Suggested fixes

## Rules

- Be specific.
- Reference file paths and line ranges when possible.
- Do not rewrite the code unless explicitly asked.
- Separate must-fix from nice-to-have.
