# Test Creation Prompt

## Goal

Add or improve tests for:

<target behavior>

## Required process

1. Identify existing test style.
2. Identify behavior to verify.
3. Add minimal but meaningful tests.
4. Include negative cases where relevant.
5. Run relevant test command.
6. Report test coverage added.

## Rules

- Test behavior, not implementation details.
- Do not weaken existing tests.
- Do not skip flaky tests without approval.
- Prefer deterministic tests.
