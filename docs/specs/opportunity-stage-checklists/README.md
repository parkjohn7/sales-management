# 영업기회 스테이지 체크리스트 운영 기준

이 문서는 영업기회 단계 전환을 체크리스트 기반으로 운영하는 기준 문서입니다.

## 동작 방식

1. 영업기회가 생성되면 현재 단계에 맞는 체크리스트가 준비됩니다.
2. 해당 영업기회에 활동이 1건 이상 등록되면 체크리스트가 활성화됩니다.
3. 현재 단계의 체크리스트 항목이 모두 완료되면 다음 단계로 자동 전환됩니다.
4. 자동 전환 순서는 `LEAD -> QUALIFIED -> PROPOSAL -> NEGOTIATION -> CLOSED_WON` 입니다.
5. `CLOSED_LOST` 는 체크리스트 자동 전환 대상이 아니며, 사용자가 종료 사유와 함께 수동으로 처리합니다.
