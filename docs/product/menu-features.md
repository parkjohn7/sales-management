# 메뉴별 기능 설명

## 대시보드
- KPI(신규 리드, Hot Lead, Forecast, 활동) 조회
- 파이프라인/기회 현황 시각화

## 리드
- 리드 등록/수정
- 리드품질/리드처리상태 확인
- 리드→고객사/영업기회 전환

## 고객사
- 고객사 등록/수정/삭제
- 표준 산업 선택, 대표전화/영업담당자 매핑
- 연락처 등록/수정/삭제

## 영업기회
- 영업기회 등록/수정
- 단계/유형/금액/Forecast 관리

## 활동
- 활동 등록/수정/삭제
- 활동유형/일시/메모 관리
- 다음활동제목/유형/기한/우선순위 관리
- 영업기회/리드 상호 배타 선택

## 리포트
- 채널 성과, 담당자 활동 리포트

## 연동
- 홈페이지/챗봇 리드 인입 테스트

## 관리자
- 단계별 확률 및 운영 정책 관리

## 로그인관리
- 로그인 사용자(관리자/조직장/영업담당자) 관리
- 이메일 기반 계정, 비밀번호 정책, 메일 발송 연계
