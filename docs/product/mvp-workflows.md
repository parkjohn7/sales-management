# MVP 업무 흐름

## 1. 리드 처리

1. 사용자가 리드를 직접 등록하거나 홈페이지/챗봇 연동 API로 리드가 생성된다.
2. BANT와 행동 데이터로 리드 점수와 등급이 자동 계산된다.
3. Hot Lead는 우선 처리 대상으로 대시보드에 표시된다.
4. 팀장 또는 관리자가 담당자를 배정한다.

## 2. 리드 전환

1. 담당자가 리드 상세를 검토한다.
2. 전환을 실행하면 고객사, 연락처, 영업기회가 하나의 트랜잭션으로 생성된다.
3. 리드 상태는 `CONVERTED`가 된다.

## 3. 영업기회 진행

1. 담당자가 예상 금액과 예상 수주일을 관리한다.
2. 단계가 변경되면 StageHistory가 저장된다.
3. 금액 또는 단계가 바뀌면 Forecast가 즉시 재계산된다.
4. `CLOSED_LOST` 처리 시 실패 사유는 필수다.

## 4. 활동 기록

1. 담당자는 리드 또는 영업기회에 미팅, 전화, 이메일, 제안서 송부 기록을 남긴다.
2. 활동 데이터는 대시보드의 담당자 활동량 KPI로 집계된다.

## 5. 대시보드 확인

1. 담당자는 본인 리드와 영업기회를 중심으로 현황을 본다.
2. 팀장은 팀 단위 파이프라인과 Forecast를 본다.
3. 경영진은 전체 Forecast와 Closed Won 현황을 본다.
