# Cherrysales 변경 이력 (MVP 진행 로그)

## 2026-06-01 업데이트

### 공통 UI/UX
- 전반적인 체리톤 UI 정리 및 버튼 색상 통일.
- 목록 기반 화면을 카드형보다 엑셀형 로우/테이블 중심으로 개편.
- 주요 메뉴별 등록/수정 폼 + 목록 선택 패턴 통일.
- 목록 테이블 스크롤/가독성 개선.
- 모든 목록 헤더 가운데 정렬로 통일.

### 리드
- 리드 상세/전환 패널 제거.
- 리드 목록 행 선택 시 좌측 폼이 등록→수정 모드로 전환.
- `영업기회 전환` 버튼으로 고객사/영업기회 생성 연동.
- 용어 변경:
  - `등급` → `리드품질`
  - `상태` → `리드처리상태`
- 리드소스 값별 설명(Direct/Web/Partner/Event) 툴팁 및 선택값 설명 추가.

### 고객사/연락처
- 고객사 `휴대폰`을 `대표전화`로 용어 변경.
- 산업 입력을 표준 산업 선택형 드롭다운으로 변경.
- `담당자` 의미를 `영업담당자`(우리 회사 오너)로 명확화.
- 연락처 폼 레이아웃 변경:
  - 이메일/휴대폰 2열
  - 직책/부서 2열
- 연락처 역할에 `unknow`(값: `UNKNOWN`) 추가 및 기본값 반영.
- 연락처 목록 휴대폰 중복 표시 제거(모바일 휴대폰 1개만 표시).

### 영업기회
- 사업별 스테이지 매핑 제거.
- 영업기회 등록/수정 화면을 리드와 유사한 패턴으로 재구성.
- 금액 입력/표시를 천 단위 콤마 형식으로 통일.

### 활동
- 활동 등록 `유형`과 활동 목록 `유형` 라벨을 동일한 한글 표시로 통일.
- 영업기회/리드는 둘 중 하나만 선택되도록 상호 디스에이블 처리.
- 목록의 `기한`, 연락처 목록의 `부서`는 가로 표시 유지(줄바꿈/세로 쪼개짐 방지).
- 활동 등록 폼에서 `기한/상태/우선순위` 입력 제거.
- 활동 목록에서 `기한/상태/우선순위/작업` 컬럼 제거.
- `내용` 용어를 `메모`로 통일.
- 활동 폼 하단에 `다음활동`, `다음활동유형`, `다음활동기한`, `다음활동우선순위` 입력 추가.
- 활동 목록에 다음활동 4개 컬럼 추가.

### 보안/CI
- GitHub `Security Checks` 워크플로우의 자기탐지(false positive) 수정.
- 시크릿 검사 패턴 및 제외 규칙 정리.

### 품질/운영
- 프론트 타입체크 및 테스트(Vitest) 기준 유지.
- 코드 수정 시 기본 프로세스로 커밋/푸시 진행.

### 2026-06-01 추가 패치 (영업기회/활동)
- 영업기회 등록 폼 고객사 값의 기본값을 빈 값으로 두고 `고객사 선택` placeholder를 기본 노출.
- 영업기회 수정 시 `owner_name`이 `owner_id`로 잘못 저장되는 문제를 수정해 종료사유 저장 실패 케이스를 보완.
- 영업기회 Won/Lost 종료사유 입력 UX와 목록 반영 동작 재점검.
