# Review PR Skill

## When to use

Use this skill before opening or merging a PR.

## Procedure

1. Read review rules.
2. Inspect diff.
3. Check changed files against task spec.
4. Check tests.
5. Check architecture boundary.
6. Check security risk.
7. Produce review report.

## Output

```markdown
# Review Report

## Blocking issues

## Non-blocking issues

## Missing tests

## Architecture risks

## Security risks

## Recommendation
```

## Rule

Do not modify files during review unless explicitly asked.
